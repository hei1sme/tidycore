# Installation

Download the Windows EXE or ZIP from the official GitHub Releases page. No installer or Python
installation is needed for the packaged executable. Start paused, select a folder
in Settings, save, then start watching. Do not place the executable inside a folder
you intend to organize; TidyCore protects its own application and data directories.

State lives in `%LOCALAPPDATA%\TidyCore`. Exiting and replacing the EXE does not
remove state. The executable is unsigned; release checksums identify the artifacts.

See the [README](../README.md) for operation, development setup and isolated tests.
