# TidyCore v2.2.0 — Fluent workspace

A redesigned native Windows interface and a substantial reliability update since v2.0.1.

## New workspace

- Windows 11 / Fluent-inspired navigation, typography, system glyphs and layered surfaces.
- Searchable history with state filters, readable badges and Ctrl+F.
- General, File type rules and Ignored items settings tabs with a persistent Save action.
- A collapsible activity log that opens on errors; compact layout and 125% scaling checks.

## Safer organization

- First launch starts paused with no folder selected.
- Durable per-user settings/history, atomic configuration saves and live target reload.
- Correct pause/resume/shutdown, download rename handling and non-overwriting collisions.
- A recoverable SQLite operation journal, migration backups and content-checked persistent undo.
- Reopening the EXE restores its running tray instance. Updates are manual; unsafe self-replacement is retired.

## Download and validation

Extract **TidyCore-v2.2.0-Windows.zip** and run **TidyCore.exe**, or use the standalone
**TidyCore-v2.2.0.exe**. Review **SHA256SUMS.txt** for artifact checksums.

37 automated tests passed. Source and packaged native checks covered synthetic
file contents, collisions, settings, restart, undo, background/tray operation,
retargeting, search/filters and minimum-size/125% scaling behavior.

The EXE is **unsigned**. Other operating systems, cloud sync/network shares,
physical power cuts and actual Windows login startup are not validated. Undo
exclusions persist without a reset UI. Counts summarize recorded moves, not a live
disk inventory. See the repository validation and recovery documents for details.
