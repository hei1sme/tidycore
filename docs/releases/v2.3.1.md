# TidyCore v2.3.1 — Optional update checks

- **About** can check GitHub for a newer stable TidyCore release.
- **Settings > General > Check for updates on launch** enables a check each time
  TidyCore starts. The setting defaults to off.

Download the Windows ZIP, extract it outside your watched folder, and run
`TidyCore.exe`. If upgrading, exit the old copy before replacing it. Settings
and history remain in your existing TidyCore data directory.

TidyCore remains a portable unsigned application. Updates are downloaded and
installed manually. The release includes SHA-256 checksums for file integrity.
