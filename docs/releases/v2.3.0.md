# TidyCore v2.3.0 — Quiet startup and automatic watching

Settings → General now has three independent startup controls:

- **Run TidyCore when I sign in to Windows** — optional Windows sign-in startup.
- **Start in the system tray** — launch without opening the window.
- **Start watching automatically on launch** — begin organizing a valid configured
  folder immediately, with no manual Start action.

For an existing v2.2.x installation, enable automatic watching once and save; the
old start-paused preference is preserved. Fresh setups default to automatic watching
and tray startup once a folder is configured. First-time setup/recovery still opens
the window; if no tray is available, the window remains accessible. Preferences
apply on the next launch. Changing folders stays paused for the current session.

Launching the EXE again opens the existing window. A Windows sign-in launch leaves
an existing instance undisturbed. Startup commands recognize the previous version's
registration and refresh it when you explicitly save Windows startup enabled.

Download the ZIP and extract outside your watched folder. Exit the old version
before running the new EXE. This remains a portable, unsigned application with
manual updates; it does not include an installer or automatic updater.

Validation uses native Windows Python 3.12.10 and isolated synthetic inputs.
All 57 tests passed, along with four packaged-EXE startup checks using the offscreen
Qt platform. Tray availability is simulated for the hidden-window entry-point check.
Interactive desktop inspection is deferred at the user's request. No real startup
registration or personal watched-folder contents are changed during validation.
