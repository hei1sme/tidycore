# TidyCore v2.2.1 — Startup recovery

Fixes startup failing when an updated EXE is downloaded into the saved watched
folder, such as Downloads. TidyCore now opens Settings paused with an explanation
and a temporarily empty target. Move the app outside the folder you want to
organize, then select that folder and save.

Saved settings and history are retained. Saving an overlapping target is still
blocked. Corrupt settings and database errors still stop startup visibly.

Download the Windows ZIP, extract it outside your watched folder and run
TidyCore.exe. Exit an older running copy first. No Python installation is needed.

Validation: native Windows Python 3.12.10 regression tests, including offscreen Qt
coverage of executable/state/resource overlap recovery and history preservation.
No interactive screen inspection was performed for this patch at the user's request.
